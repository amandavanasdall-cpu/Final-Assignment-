# Final-Assignment-
This assignment was completed for Nexford Univeristy 
The application collects participant information about the following; age, gender, total income, and spending. The collected information is stored in MongoDB and is exports to a csv file. 

This project uses Python, Flash, MongoDB, Pandas, Matplotlib, Seaborn, and Juptyer Notebook. 

The charts created show income by age and gender spending.
